# Bundle security policy

This role bundle follows the repository [security policy](../../SECURITY.md).
Report the bundle name, canonical skill ID, affected commit, and a synthetic
reproduction through the private reporting process described there. Do not
post credentials or exploit details in public issues.

Skills require the user's authorization for consequential operations and
must not use unrelated credentials, files, accounts, or systems. Follow the
root policy and the skill's more specific execution boundaries.
